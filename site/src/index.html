Maths, climbed one block at a time.

Zigrt decides what each child should learn next, teaches it in small steps, and brings it back for review just before it would be forgotten. The name is short for ziggurat: a tower climbed one tier at a time.

Install Read the parent's guide
  • 255 lessons, K to Grade 5
  • One container
  • SQLite or Postgres
  • No cloud, no AI, no ads

A tutor that remembers everything

Every answer is kept. From them, Zigrt works out what each child knows, what they are ready for, and what is about to slip.

  • 🧱

    Mastery, block by block

    255 blocks from counting to fractions, each built on the ones under it. A child is only taught what they have the footing for.

  • 👀

    Watch, then try

    Each step shows a worked example, then asks until it sticks. New numbers every time, never the same question twice.

  • 🔁

    Reviews just in time

    Spaced reviews from a day to eight months apart. Harder work counts as review for the easier blocks inside it.

  • 🎯

    Start where they are

    An adaptive placement check, or start a child at their grade in one tap. They skip what they know.

  • 📐

    Pictures throughout

    Ten frames, coins, number lines, area models, graphs and protractors, drawn on the server as crisp SVG.

  • 🖨️

    Drills and worksheets

    Fact drills with a big number pad, and printable worksheets with answer keys. Assign one and it waits on the child's home.

  • 📊

    A view for parents

    XP each day, what was done, who is stuck, and a weekly email. Daily goals, rest days and streaks per child.

  • 🔒

    Private by default

    No telemetry, no CDN, no outbound requests, no AI at run time. Pages work without JavaScript. A JSON API and MCP server if you want them.

A tour

Taken from the demo household: two children, Ada and Ben, after two months of after-school climbing.

Their own tower

Children sign in with a PIN on a big number pad and see one thing to do next. Each finished block goes on their tower; each grade is a tier, and each strand a face of it.

How Zigrt teaches →

Pictures that do the explaining

Every lesson step starts with a worked example. Area models split a multiplication into parts; a protractor shows which scale to read. The figures are drawn by the server for each problem, so they always match the numbers.

How lessons are written →

One page per child

XP each day against the goal, everything they did with the score, and their tower down to each block. The bell tells you when someone is locked out, a lesson keeps stopping, or a grade is finished.

Keeping an eye on progress →

Start where they are

A child who has finished Grade 1 shouldn't sit through it again. Start them at their grade, or let the placement check find out in up to 35 questions. Either way, earlier blocks still come back as quick reviews.

Choosing where a child starts →

Phone, tablet or laptop, light or dark

Big targets for small hands, a calm parent side, and a dark theme that follows the device. Drills give facts a quick workout; worksheets print cleanly with an answer key on its own page.

Install

One container and one volume. Put it behind your TLS reverse proxy (Caddy, Traefik, a Gateway) and you're done.

Docker Compose

mkdir zigrt && cd zigrt
curl -fsSLO https://raw.githubusercontent.com/chinny-labs/zigrt/main/deploy/compose/compose.yaml
openssl rand -base64 32 > zigrt_key.txt
docker compose up -d
docker compose logs zigrt | grep -i "setup token"

Open https://<host>/setup, paste the setup token and create the first parent. Then add your children.

Kubernetes (Helm)

helm install zigrt oci://ghcr.io/chinny-labs/charts/zigrt \
  --version 1.1.0 --namespace zigrt --create-namespace
kubectl logs -n zigrt deploy/zigrt | grep -i "setup token"

Multi-arch images (amd64, arm64). Nightly SQLite snapshots, a portable export between SQLite and Postgres, /healthz, /readyz and Prometheus metrics.
